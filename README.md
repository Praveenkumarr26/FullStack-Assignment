# 🎬 VideoGuard

A complete **full-stack video management platform** with intelligent content sensitivity analysis, real-time processing, and seamless video streaming.

## ✨ Features

- 📹 **Video Upload** - Drag-and-drop interface with progress tracking
- 🔍 **Content Analysis** - Real-time sensitivity detection
- ⚡ **Live Updates** - Socket.io powered real-time events
- 🎥 **Video Streaming** - HTTP range-request support
- 🔐 **Security** - JWT auth, multi-tenant architecture, RBAC
- 📱 **Responsive** - Mobile-first design with Tailwind CSS

## 🏗️ Tech Stack

| Layer | Technologies |
|-------|--------------|
| **Backend** | Node.js, Express, MongoDB, Socket.io |
| **Frontend** | React 18, Vite, Tailwind CSS, Socket.io Client |
| **Database** | MongoDB Atlas |
| **Tools** | FFmpeg, Multer, JWT, Bcryptjs |
